{! ! THE shared input include: PosKeyboards renderers (price pad, search pad ! with digits, ALPHA keyboard — a FIXED 10-column grid needing ~554px ! minimum width) and the PosInput SINGLETON. CONTRACTS: PosInput.setup wires ! ONE input at a time (a second setup steals the buffer — one active binding ! per page); external pads can feed the same buffer through ! PosInput.handleKey(k); initialValue is the supported prefill (never poke ! .buffer directly). defaultValue quirks and modes: 'integer'/'decimal'/'text' ! govern what keys append. ! THE DISPLAY IS NOT A FIELD. A till has no physical keyboard, so a visible ! there shows a caret waiting for keystrokes that never come — and ! invites someone to plug one in. Every display is a text element carrying the ! .pad-display class (the theme holds its height and its placeholder), and what ! is posted travels in a hidden input named by hiddenId. updateDisplay writes ! textContent on such an element and still writes .value on the few that are ! inputs, and padText(el) reads a display back whichever it is. !}
